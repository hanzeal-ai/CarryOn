# CLI 更新与卸载

```sh
connectnow update --check     # 检查官方最新正式发布，不安装
connectnow update             # 下载对应 macOS 架构的 CLI，校验并切换命令入口
connectnow update --package /路径/ConnectNow-0.3.0-macos-arm64-cli.tar.gz
connectnow uninstall          # 移除 CLI 命令入口
```

在线更新读取 `hanzeal-ai/ConnectNow` 的 GitHub Releases。发布必须提供当前架构的 `ConnectNow-版本-macos-arm64-cli.tar.gz` 或 `x86_64` 包，以及 `SHA256SUMS`。无法访问发布、缺少资源、校验不匹配或新程序版本检查失败时，不切换现有 CLI。在线更新只采用更高的正式版本；需要每次正式发布递增版本号。

本地更新用于已下载或内部构建的安装包，包的同一目录必须包含 `SHA256SUMS`，并与本机架构匹配。只使用可信来源的安装包及校验文件；本地方式允许同版本构建的替换。`update --check` 不可与 `--package` 混用。

更新针对通过安装器建立的 CLI 符号链接。新版本安装在 `~/.local/share/connectnow-releases/` 下，通过原子替换符号链接切换入口，旧版本保留。源码运行和 Python 包安装不会被这个命令替换，请使用原来的包管理方式。

## 与桌面端和后台的关系

更新会先准备并验证新版，然后通过统一服务目录发现当前运行中的工作区，逐一停止后台、切换 CLI 入口，再用新版恢复原端口、数据目录、Codex 目录、桥接状态和控制会话。原本未运行的服务保持关闭；桌面应用本身不会替换。绑定、Token 和控制权限继续使用原数据目录。

启动或状态恢复失败时，自动恢复原 CLI 入口，并使用各服务原来的可执行程序恢复后台；恢复失败会明确列出错误。无法识别原程序的源码服务会在停止前拒绝更新。更新期间连接会短暂中断；Codex 已接收的任务继续执行，投递中断的请求可能标记为待核对，不会自动重发。代码回退不等于数据回退。旧程序目录保留用于恢复，不自动删除可能仍被桌面端或其他进程使用的文件。

卸载仅移除 CLI 命令入口。桌面端、正在运行的后台、程序版本目录和所有用户数据保留，避免卸载一个操作界面时破坏共享服务。此命令不执行清理数据或卸载桌面应用。以后可重新安装 CLI，或重新建立指向保留版本的符号链接。

## 验证和交付边界

`python3 -m unittest discover -s tests -p test_maintenance.py -v` 验证安全解包、架构与 SHA256 校验、失败时旧入口不变、成功切换、旧版本保留，多服务自动恢复、失败回退、关闭状态保持，以及卸载不删除共享程序与数据。

这是安装入口和下载执行相关的 R2 变更。代码与隔离测试不等于正式发布批准；实际在线发布验证和独立审查尚需完成。本次开发不操作用户的安装入口或运行中的服务。
