# 工作区与云端关系

一个用户账号可以绑定多台电脑及多个工作区。首次工作区绑定由用户在手机确认；新增同工作区连接可由电脑端核对已有账号与权限后明确确认加入，无需重复扫码。仅有相同目录或展示分组不会自动授权。

工作区可包含桌面端与 CLI 等多个连接。展示分组在本机生成、云端按绑定所有者隔离；
明确加入的连接共用一份工作区成员权限，各自保留独立凭证、执行路由和本机远程操作开关。
移除一个连接保留其他连接；撤销工作区成员权限对全部已加入连接生效。具体契约见 WORKSPACE.md。

默认 IPC 工作区与每个独立 app-server 工作区分别保存配置、服务状态和投递日志。现有多个云端绑定按 ID 分别管理；凭证恢复仅替换所选云端并保留其余配置。任何一次断网均不撤销已保存授权。

初始化及定向申请见 [ONBOARDING.md](ONBOARDING.md)，CLI 入口见 [CONFIGURATION.md](CONFIGURATION.md)。本地断开云端连接、云端撤销成员授权和本地删除工作区保持不同语义。
