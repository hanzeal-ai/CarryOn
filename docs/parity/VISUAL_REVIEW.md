# iOS 视觉独立审查

审查日期：2026-10-02。结论仅覆盖下列公开参考与实际渲染，不代表全产品或像素级一致。

## 原始证据

官方参考：`/tmp/carryon-official-reference/home.jpg`、`create.jpg`、`composer.jpg`。home 是包含设备外框的裁切图；另外两张是输入区域特写，不能直接以整图像素比较。应先裁至屏幕内容，再按相同屏幕宽度归一化。

实际截图：`.runtime/tabs-regression/tabs-top.png`、`.runtime/parity-regression/parity-new-single.png`、`parity-new-image.png`。这些来自生产 SwiftUI 控件和真实系统键盘，fixture 提供隔离数据。`.runtime/home-regression/home.png` 是故意制造旧模型不可用的失败测试弹层，不能用作正常首页。

## 已观察差异与修改状态

1. 输入框单行高度按屏宽归一化估计约 100pt，官方约 87pt。文字行到操作栏间距偏松。根任务已将纵向密度减少 12pt；已重新渲染 parity-new-single / parity-new-image 并检查输入框与真实键盘；整体一致性仍未验收。
2. 发送按钮紫色偏深，模型名称尾部有明显下箭头。根任务已采用 composer 专属浅紫并移除箭头；新截图已确认采用浅紫且没有尾部箭头；未声明像素级一致。
3. 官方操作栏显示附件、权限/设置、模型、麦克风和发送。此前当前实现主要为附件、模型、发送，并额外显示技能按钮。根任务已将已加载会话的照片与技能收进真实“＋”菜单。权限及语音须以实际能力实现，不能添加空按钮冒充一致。
4. 官方新建配置展示主机、项目、工作树、环境四行；当前主要是主机与项目。直连创建会隐藏项目。这是能力与交互差异，不能仅用 CSS/SwiftUI 外观处理；不支持的配置不得伪装可用。
5. 当前项目行原有 44pt 点击高度加 8pt 行间距，官方参考估计约 45pt 节距。根任务已去掉项目内行间距并保留 44pt 点击高度；待正常数据截图复核。
6. 当前技能是正文之外的 chips；官方 composer 特写是正文内带图标的蓝色引用。属于编辑器能力差异，不应将独立 chips 描述为相同交互。
7. 模型选择目前使用半屏 Form。三张官方参考没有打开模型弹层，缺乏足够证据判定其官方形式；不能仅凭偏好要求改成某种弹层并宣称一致。

## fixture 内容与真实样式的区别

- tabs-top 中有五个项目、缓存失败重试条；官方 home 只有三个项目。最近会话下移主要受这些内容影响，不能全归因于布局。
- 首页标题 34pt、左右约 24pt、标题和 Projects 的纵向起点已较接近参考；没有依据整体放大或缩小页面。
- 旧截图菜单图标浅灰，当前源码已填充 Design.ink；须以新截图判断。
- 中英文键盘、时间、项目名称、蓝色测试图片均属内容/系统环境差异。
- 官方 home 未显示完整 Recents 列表，不能据此确认当前会话行的精确样式。

## 下一次验收

采用相同数量的项目、正常连接无错误、固定文本和相同键盘语言，输出正常首页、空白新建、单行、三行、带图及已选技能的生产截图。按屏宽归一化比较输入框高度、内边距、操作栏位置与颜色；动态字体和 44pt 触摸区域保持可用。补齐官方弹层/会话列表证据前，相关一致性结论保持未验证。
