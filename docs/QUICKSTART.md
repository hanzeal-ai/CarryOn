# 从手机继续一次工作

适用：在另一台设备上查看和继续自己的 Codex 工作。电脑必须保持在线；云端控制台不替代本机执行环境。

## 第一次连接

1. 使用与你的 macOS 和架构匹配的 CarryOn 安装包，打开应用进入初始化向导。安装方式与发行限制见 [安装说明](INSTALL.md)。
2. 在电脑生成绑定二维码，用已登录的 CarryOn 手机端扫码，核对工作区与权限后确认。
3. 启动本机服务。默认工作区连接 Codex App；独立工作区使用独立 App Server，按所选模式完成模型登录。
4. 手机打开正确工作区和会话，核对最新内容。只读权限能查看；需要发送或审批时，在电脑端明确授予相应权限。

**成功标志：** 能看到正确会话的最新内容和连接状态。历史可读不代表执行机在线。

已安装 CLI 时可运行：

```sh
carryon init
carryon start
carryon status
```

初始化中断后再次执行 `carryon init` 继续。正常使用不重复绑定。关闭网页不停止服务。

## 无法继续时

- 看不到会话：核对工作区和列表筛选，桌面原生会话可能尚未加载。
- 状态未知：先检查电脑网络、服务与 Codex 连接，不将缓存历史视为实时状态。
- 发送结果未知：查询原请求状态，不反复新建或重发同一任务。
- 不能执行操作：核对本机授权和当前后端支持的操作，不在云端提升本机权限。
