# 手机发送与动态首屏同步

目标：普通消息提交不依赖手机历史窗口下载；动态已有摘要可立即阅读，详情未完成或失败时仍可进入会话。

风险 R2：改变客户端连接/操作就绪状态，并向公共动态和通知事件投影增加只读摘要。用户已授权修复、提交和推送 main；不包含安装到真机、部署网关/CLI 或发布 iOS。

影响：iOS AppModel 保留订阅切换时的健康连接，冷连接并行请求工作区状态。普通 compose 保留身份、前台、工作区权限、只读、请求编号和服务端状态裁决；依赖轮次的操作使用独立的历史就绪条件。后台到期、连接失败、工作区切换及历史错误均清理相关就绪标记。Workspace 从原生事件生成有界预览，现有 notification_events JSON 保存预览；动态列表按需取现有预览，不触发 history 读取。预览不含操作控件，不推进已读。详情成功后只确认请求开始前捕获的读游标。

恢复：回退本次提交并重新构建。新增字段为可选 JSON 字段，旧代码忽略即可，无数据库迁移、数据删除或原生会话回滚。

验证：使用现有 Python unittest、Swift Package、设备目标构建和真实 AppModel 模拟器回归。专项覆盖历史未返回时通过 HTTP compose、冷连接状态先于历史、远程控制关闭时拒绝发送，以及失败/中断/尾部过程消息的预览语义、卸载重启读取、长度限制与不触发历史请求。模拟器使用隔离 transport，不向真实 Codex 投递消息。

独立审查：独立 Agent 读取原始源码、差异与测试，可以要求修改/拒绝；本轮已修正其指出的失败/中断预览误标、断线后陈旧操作状态和已读游标竞态。规范优先的 GPT-5.6 Luna 未在可用模型列表中，因此使用可用继承模型。最终独立源码结论为有条件接受，无剩余代码阻断项；真机与生产链路仍需人工验收。

已验证：Python 全量 519 项完成（1 项可选依赖跳过），最终 Workspace 专项 39 项通过；Swift Core 109 项通过；Node 客户端 18 项通过；Python 编译、JS 语法和最终差异检查通过。最终设备目标未签名构建成功。真实 AppModel 模拟器回归 33 项全部通过（`.runtime/cache-regression/result.json`），含历史返回前 HTTP 发送、冷连接轻量状态就绪、远程控制关闭拒绝发送、后台恢复与作用域隔离。

实施方通过 CUA 实际打开动态详情，在受控 history 503 响应下观察到摘要、错误、重试和可用的「进入会话」按钮；原始 AX 与截图位于本次工具记录。审查者核验了原始结果文件和源码，未独立查看详情截图。模拟器随后意外关闭，未继续完成按钮点击跳转验收。初期 CoreSimulator/CoreLocation 故障经重启测试服务恢复，测试结果使用本轮新文件，不使用旧结果。

未验证：真实手机、真实云端延迟和生产原生投递。仅提交推送源码，不发布安装包，不修改生产服务。
