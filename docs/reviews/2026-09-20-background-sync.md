# iOS 短暂后台同步

目标：切换到其他 App 时使用系统允许的最长后台执行时间，短暂切回复用健康连接；系统通知时间到期后关闭连接，返回前台重新连接并同步。

AppModel 通过 UIApplication.beginBackgroundTask 申请执行时间，以 expiration handler 为到期依据，不写死秒数、不自行续租。有效期内只保持主会话流（含已订阅的临时聊天），保持接收超时检查；辅助预取和目录轮询仍停止。短暂返回前台结束后台任务并 ping 原连接，不显示虚假重连、不重新订阅。到期或系统拒绝申请时取消读取和订阅任务、关闭连接；前台再启动更新循环。

状态隔离：后台任务带 generation，旧到期回调不能关闭新连接；工作区和认证 epoch 变更清理后台任务。后台不允许写入，不标记已读，不重放任何已提交操作。没有新增后台模式或依赖。

验证入口：`swift test --package-path iOS`；`python3 tests/run_ios_cache_regression.py <simulator-id>`。回归复用真实 AppModel 和 Core，HTTP/WebSocket 使用隔离 transport，覆盖后台历史更新、短回前台连接和订阅保持、重复到期清理、后台禁止重连、到期后的前台重连与工作区隔离。模拟到期调用验证清理路径，实际系统分配时长需真机观察，不能从模拟器推断固定秒数。

恢复：撤回本次 AppModel、README 和缓存回归 fixture 差异并重新构建；无数据库或服务端变化。原有旧会话历史同步变更独立保留。本次不发布、不安装到真实设备。

结果：完整模拟器 App 构建成功；缓存/后台模拟器回归 24 项全部通过，证据 `.runtime/cache-regression/result.json`；Swift 核心 97 项通过。独立源码审查未发现阻断项，最终 diff 检查通过。系统真实到期时长、真机后台调度及真实云端链路未验证；未将测试包替换到真实设备。
