# iOS 全局性能优化与底部导航排查

用户报告 iOS 底部导航切换卡死，后授权“全部优化一下”。本次完成已识别的六类性能优化；尚未在原 iOS 18.1 真机复现或验收卡死消失，不将模拟器通过等同于根因确认。

## 变更与影响

- 实时任务回执：`PendingWrites` 批量对账，无对应请求或数据不变时跳过编码与 UserDefaults 写入；一次批次实际发生变化时仅保存一次。保留创建会话等待原生 ID、账号/目标隔离与幂等语义。
- 长会话导航：按历史版本构建消息索引，按钮读取索引，消除逐按钮重复扫描。
- 文件改动：后台生成不可变统计快照，卡片与行复用统计，保留未知补丁不显示伪造总数的行为。
- 草稿：后台串行编码与原子写文件，同一文件等待中的快照合并为最新版本。账号切换读取前等待旧写入；写失败保留内存副本，损坏文件不覆盖。应用进入后台申请有限时间完成 flush。
- Markdown：独立 actor 解析并设置有界缓存，主会话与临时聊天在提交列表更新前准备解析树（临时聊天仅保留最多 120 条窗口），避免首帧空行及后续高度变化；流式请求合并，离开页面后阻止过期结果更新。
- 底部切换：Root 分别持有项目、会话、动态列表状态，保留搜索、筛选、列表及滚动位置，30 秒内复用成功加载结果；账号或工作区变化清空。保持原导航容器与工具栏布局。

风险级别 R2：涉及草稿持久化与消息状态生命周期。未改变草稿文件格式、存储地址、请求协议或权限规则，没有新增依赖。

## 验证证据

- `swift test --package-path iOS`：116 项 Swift Testing、4 项 XCTest 全部通过。新增覆盖批量对账写入次数、跨账号隔离、导航索引、未知 diff、延迟写入期间编辑、合并保存、清空后不复活旧草稿。
- `iOS/scripts/compile-device.sh`：arm64 iPhone 目标 Debug 编译通过（无签名、未安装）。
- `python3 tests/run_ios_navigation_regression.py <simulator-id> tabs`：iOS 26.5 Simulator，18 次切换、237 帧，最大帧间隔 0.195 秒、最大切换等待 0.308 秒；搜索/50 条列表/滚动锚点保留，实际滚动偏移 239.67 点、截图首项为项目 3；项目/会话模式筛选隔离，工作区切换清空，Markdown 预解析可读全部通过。通知驱动真实选择状态，不模拟物理点击或连接真实服务。
- 同一 runner 的 `navigation`：定位、活动目标消费、浮动按钮高度、追加/流式消息阅读位置全部通过；位置 391.8333 → 391.8335 点。优化前该用例的阅读位置断言失败约 89 点。
- 同一 runner 的 `alignment`：主会话与临时聊天操作、只读限制、旧目标拒绝、失败回执、未知请求 ID 保留、创建等待原生 ID 等检查全部通过。
- 已检查最终底部切换截图：搜索和滚动锚点保留，工具栏与原底部导航存在，无额外系统 tabbar。

本机 Swift Release 微基准（不是 iPhone 帧率或端到端延迟）：

| 场景 | 优化前主线程路径 | 优化后主线程路径 |
| --- | --- | --- |
| 2,000 条消息导航选择 | 204.04 ms | 0.069 ms（已建索引） |
| 100 个文件、各 2,000 行 diff 统计展示 | 121.60 ms | 约 0.001 ms（已建快照） |
| 24 MB 草稿 | 65.68 ms 同步保存 | 0.010 ms 入队，编码/落盘后台执行 |
| 100 条无变化任务回执 | 6.70 ms、200 次 set | 0 次 set |

后台解析、索引建立与实际磁盘写入仍有成本。模拟器帧间隔存在尖峰，不能声称达到稳定 60 fps。原始基准、日志与三类结果保存在 `.runtime/performance-optimization/`；对应构建日志和截图在 `.runtime/{tabs,navigation,alignment}-regression/`。

## 独立审查与恢复

- 独立审查：performance_review 基于原始源码、测试和最终截图独立复核，结论“有条件接受”，无代码阻断项。已按要求修正临时聊天全历史预解析、不同文本回退与模式筛选串用问题。条件为 iOS 18.1 真机冻结仍属部分验证，不可声称根因确认或真机已修复；变更详情在新快照完成前短暂保留旧展示，是记录在案的非阻断观察。原优先审查模型不可用，已说明后使用 GPT-6 Luna。
- 在当前 main（起点 e1d9c5e）上完成，保留大量既有未提交修改；没有提交、推送、部署或替换真机安装包。
- 本任务开始时 Swift 源码和相关测试快照在 `.runtime/performance-optimization-baseline/`，独立差异为 `.runtime/performance-optimization/changes.diff`。恢复时只逆向应用本次差异并检查后续改动，禁止整体 reset 仓库或覆盖用户已有工作。未进行数据迁移，磁盘草稿保持原格式，可由旧实现读取。
- 真机 iPhone 16 Pro Max / iOS 18.1 的 Time Profiler 因 ktrace 失败、LLDB 因符号错误未取得可信卡死堆栈，设备随后断开；已结束本地调试器。后续人工验收需重新连接解锁的原手机，验证连续底部切换、长会话流式输出、含图片草稿和后台恢复。
