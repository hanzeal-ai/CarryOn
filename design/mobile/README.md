# ConnectNow 移动端交互原型

系统字体、冷灰背景、白色分组容器。页面使用紧凑导航，主要任务操作集中在对话输入区，设置底部提供退出。

## 预览

直接打开 index.html，或在项目根目录运行：

```sh
python3 -m http.server 8891 --bind 127.0.0.1 --directory design/mobile
```

访问 http://127.0.0.1:8891，使用 `demo` 登录。全部操作仅作用于本地演示数据，不会发送到真实设备。

详细功能、验证和接入边界见 [FUNCTIONS.md](FUNCTIONS.md)。运行态、权限与请求控制仍以正式系统契约为准。本目录可独立删除撤回，不影响现有控制台。
