# 产品 Logo 概念稿

设计依据：当前 README.md、docs/CONSOLE.md 与 iOS/README.md 所描述的跨端会话查看、继续任务、双向输入、审批及设备控制能力。图形表达产品用途，不代表本次验证了远程链路。现有产品界面和图标未替换。

推荐 **01 接续 / continuity**：两个开放端口通过斜向笔画连为整体，表达在另一台设备上继续原有工作。石墨黑配深青色，单色仍保留完整轮廓。无需绑定 ConnectNow 名称或首字母。

**02 双端对话 / dialogue**：相向的两个会话形状，强调指令和回应。紫色区分远端；单色依靠中心留白保持结构。更偏协作、会话产品。

**03 远程掌控 / orbit**：命令提示符置于开放轨道内，外部节点指向远端设备。赭色提供温度。开发者属性最直接，细节相对较多，优先用于 24px 以上。

上述名称仅是方案标题，并非产品改名建议。未制作尚未确定名称的字标。

## 文件

每个方向提供 3 种构图 × 3 种颜色，共 27 个独立 SVG：

- `symbol-*`：96 × 96 画布、透明底纯图形，用于导航、浏览器图标及排版。
- `app-*`：128 × 128 画布、圆角方形底，用于应用图标视觉预览。
- `badge-*`：128 × 128 画布、圆形底，用于头像和圆形容器。
- `*-color`：双色；`*-mono`：石墨黑；`*-reverse`：白色。透明底白色图形应置于深色背景。
- `overview.svg` / `overview.svg.png`：方案对比、深色背景、16 / 24 / 32 / 48px 单色与应用图标预览。

全部标志使用矢量路径与几何图形，不依赖字体、外链、位图或滤镜。总览中文字用于说明，不属于标志。

## 颜色与使用

共同深色：`#222A32`；反白：`#FFFFFF`；深色底：`#18232B`；浅色底：`#F1F3F2`。

接续强调色：`#167D91`；双端对话：`#5A61CA`；远程掌控：`#C16836`。

推荐纯图形画布至少 24px；16px 优先选择接续单色版。图形四周保留至少 12/96 画布宽度的净空。按等比缩放，不拉伸、旋转或额外添加描边、阴影。正式 iOS 图标应从矢量导出不带预制圆角的满幅背景资源，由系统裁切；此处 app 文件为构图预览，并非完整 AppIcon 资源集。

Web 示例：`<img src="continuity/symbol-color.svg" width="32" height="32" alt="产品名称">`。

在矢量设计工具中打开 SVG 可直接编辑或导出透明 PNG；建议 1x / 2x / 3x 输出。印刷使用单色版最稳定，双色印刷需单独打样校色。
